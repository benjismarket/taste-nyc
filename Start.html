Create Your First Website and Share It on GitHub

Use v0 to build a live one-page website for your event, club, project or yourself, then post its code on GitHub to collaborate and share.

Requirements: A free v0 account and a free GitHub account.

What you'll learn

A GitHub repository is a shareable home for your code that keeps every version you publish. Specifically, you’ll learn how to:

  • Turn a plain-English description with real details into a live, published website

  • Put a project’s code on GitHub and track every version you publish as a commit

  • Share a public repository that a recruiter or teammate can open and build on

What you'll build

A live one-page website with its code in a public GitHub repository under your own account. You’ll have both links ready to share and put on a resume.
